01 — About

Why version control matters in research

Reproducibility, collaboration, and never losing work to a file named final_v3_ACTUALfinal.py. Git gives every change a name, a time, and an author — so your project has a history you can trust.

  • Track everything. Every edit is recorded and reversible.
  • Work together. Branches let people work without colliding.
  • Share openly. Push to GitHub and your work is one link away.

03 — Commands

The cheat sheet

The moves we'll practice today, in the order you'll usually meet them.

git initStart tracking a folder
git cloneCopy a repo from GitHub
git statusSee what changed
git add .Stage your changes
git commitSave a snapshot
git diffCompare before & after
git logView the history
git pullGet others' changes
git pushSend yours up
git checkoutSwitch branch / restore
git mergeCombine two branches
