# Git &amp; GitHub Workshop  Demo Site

hey i am Amulya, A tiny website we use to learn version control by **changing things and tracking them**.

Open `index.html` in a browser to see it. Then edit any file, and use Git to
record what you did.

## Files

| File | What it's for |
|------|---------------|
| `index.html` | The page structure and content |
| `style.css`  | Colours, fonts, and layout |
| `script.js`  | The little bit of interactivity |
| `README.md`  | This file — GitHub shows it on the repo home page |

## Commands we practise

```bash
git init                 # start tracking this folder
git status               # see what changed
git add .                # stage all changes
git commit -m "message"  # save a snapshot
git log --oneline        # view the history
git diff                 # compare before and after
git clone <url>          # copy a repo from GitHub
git pull                 # get others' changes
git push                 # send yours up
git checkout <branch>    # switch branches
git merge <branch>       # combine branches
```

## Try it yourself

1. Add your name to the **Participants** section in `index.html`.
2. Run `git add .` then `git commit -m "add my name"`.
3. Push to GitHub and refresh — your card is live.
